Option B: Global Internet Cloud Sync (GitHub Pages)

Because GitHub Pages is a static host, connecting a free Google Firebase Realtime Database allows students from any PC anywhere in the world to sync into your Admin Portal in real time!

⚡ 60-Second Free Firebase Setup (No Credit Card Needed):
  1. Go to console.firebase.google.com with any Google account.
  2. Click "Add project" → name it arc-drone → click Continue.
  3. In the left sidebar under Build, click Realtime Database → click Create Database.
  4. Select database location (e.g. Singapore or US) → Next.
  5. Choose "Start in test mode" (allows student app to read/write) → click Enable.
  6. Copy your Database URL (e.g. https://arc-drone-xxxxx-default-rtdb.firebaseio.com/) and paste it into the box above!
  7. Click Save & Test — All PCs will now sync in real-time globally!
